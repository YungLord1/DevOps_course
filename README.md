# Currency Parser

Я реализовал клиент-серверное приложение на REST API, для получения курсов валют с сайта ЦБ РФ, реализованное по принципам чистой архитектуры.

Проект разделил на 4 слоя: Domain (сущности и порты), Application (бизнес-логика), Infrastructure (работа с внешним API) и Presentation (эндпоинты). 

В ходе работы думал подключить базу данных или кэширование, но понял, что они будут бесмысленны, т.к. сайт ЦБ РФ обновляет курс валют 1 раз в день, приложение ориентированно не на такое большое количество лиц, которые будут спамить запросами и приложение спокойно выдержит. Реализовал обработку ошибок, валидация входных данных, поддержка старых данных по датам. 

Переменные окружения вынесены в .env файл, зависимости управляются через pyproject.toml. Код асинхронный, используется httpx для запросов к ЦБ РФ.

Также пользуясь подходом IaS, была создана инфраструктура клиент-серверного приложения в Infra.c4 файле для удобства
