Что сделано:
1. Установлены необходимые версии ансибл, молекулы и тестинфра, настроеные  виртуальные окружения

2. Подключены мастер с ворккерами, настроен файл hosts.ini прописал пинг командой ansible myVMs -m ping -i inventory/hosts.ini -K, отвечает понг ![SUCCESS ping pong](images/ping.jpg) (флаг -K использовал для передачи пароля от ВМ, потом уберу флаг и создам ansible vault)

3. Инициализирована коллекция,  где были созданы 2 роли:
 1) cri-o. Роль отвечает за  настройку  среды  выполнения контейнеров. Включает в себя  модули  ядра overlay, br_netfilter и sysctl. Добавлен jinja template для создания конфигурационного файла cri-o
 2) kube. Устанавливает компонены kubeadm, kubectl, kubelet

4. При инициализации коллекции был создан site.yml, где я описал главный playbook с развертыванием crio, а затем kubelet, kubeadm и kubectl. upd: При последующих этапах выполнения дз заметил, что роль crio выдает ошибку и не идет дальше, а роль kube не сохраняет свойство идемпотентности ![Запуск плейбука с ролью kube](images/playbook.jpg). На скриншоте я запустил только роль kube, crio закомментил, тк там вылетает ошибка из-за прокси. Какието лишние файлы не успел убрать тоже...

5. Проведено тестирование с помощью молекулы. Честно признаюсь, что тут под конец уже никак не успевал разобраться и использовал игнорирование ошибок. Очень не по себе из-за этого, как только вернусь домой - сразу сяду исправлять. Конверж выполняется без failed5 раз игнорирует проблемы ![Запуск molecule converge](images/converge.jpg). Molecule verify выполняет  4 теста, 1 из которых падает, тк пакет crio не был до конца установлен. ![Запуск molecule verify](images/verify.jpg)

6. Возникшие трудности:
 1) Настройка прокси. Трудность была в скачивании файлов с разных сайтов в одной таске, для каких-то прокси подходил, для  каких-то нет. Поэтому прямо в таске прописал на какие сайты нужны прокси, а на какие не нужны(apt не скачивался с прокси)
 2) Конфликт docker и systemd. Использовал образ джеффа гирлинга, чтобы не возиться с systemd, однако там не было базовых  пакетов по  типу curl.
 3) Тяжеловато было разобраться в установке cri-o, тк до этого дз не занимался чем-то похожим.

Большое спасибо за проверку! Я бы добавил еще обязательно ansible lint, vault, ну и, коненчо, же исправил ошибки и убрал ignore. Ansible мне понравился, но самое трудное наверное было решение ошибок от молекулы и установка cri-o.
